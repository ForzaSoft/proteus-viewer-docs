# Viewport

The viewport is the main image display area. Each panel in the grid shows an independent series and can be interacted with individually.

## Context Menu

Hold **Ctrl** and **right-click** anywhere on a viewport to open the context menu. It provides quick access to series management and image adjustment options without switching toolbar modes.

### Series

- **Split Series**: Splits a multi-group series into separate viewports. Only available when the loaded series contains more than one group.
- **Series Group**: Selects which group to display in the current viewport when the series contains multiple groups.
- **Close All Panels**: Closes all viewports and resets the grid to the default single-panel layout.

### Window

- **Default Window**: Restores the default window/level for the series.
- **Full Dynamic**: Applies the full dynamic range of the image.
- **Windows**: A submenu with configurable fixed window presets (e.g. Soft Tissue, Lung, Bone for CT).

### Zoom

- **Fill Viewport**: Scales the image to fill the entire viewport.
- **Zooms**: A submenu with configurable fixed zoom level presets.

### Other

- **Reset**: Resets the viewport to its initial state (zoom, pan, window/level).
