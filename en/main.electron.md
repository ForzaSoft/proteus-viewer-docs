# Proteus Viewer

Proteus is a DICOM viewer, a specialized application designed to display and interact with medical images stored in the DICOM (Digital Imaging and Communications in Medicine) format. DICOM is the international standard for medical images and related information. This viewer allows healthcare professionals to review, analyze, and manage patient studies.

![Proteus Viewer](../images/viewer.png)

## Application Modes

Proteus Viewer has three main modes, each with specific documentation:

- **[Viewer](./viewer/main.md)** - Main mode for reviewing and analyzing medical images
- **[MPR](./mpr/main.md)** - Advanced 3D visualization and oblique reconstructions
- **[3D Volume](./volume/main.md)** - Interactive 3D volume rendering of CT series

Select the mode you're currently using to view its specific documentation.
