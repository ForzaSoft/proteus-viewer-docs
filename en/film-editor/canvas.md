# Film Canvas

The film canvas is the main work area of the Film Editor. It displays one or more pages, each divided into image cells according to the selected template.

## Pages

A film can contain multiple pages. Use the **Prev** and **Next** buttons on the left and right edges of the canvas to navigate between pages.

## Image Cells

Each page is divided into cells based on the active template. Images sent from the viewer are placed into cells sequentially. You can interact with individual cells using the mouse modes from the [Toolbar](./toolbar.md):

- **Selection**: Click a cell to select it. Selected cells are highlighted and can be repositioned, adjusted, or deleted.
- **Image Window**: Drag inside a cell to adjust its brightness and contrast independently.
- **Move**: Drag inside a cell to pan the image.
- **Zoom**: Drag inside a cell to zoom in or out.
- **Delete**: Click a cell to remove its image content.

## Context Menu

Right-clicking anywhere on the canvas opens a context menu with the following actions:

- **Select All**: Selects all image cells on the current page.
- **Unselect All**: Clears the current selection.
- **Reset**: Resets the selected cell(s) to their initial state (zoom, pan, window/level).
- **Delete**: Removes the image content from the selected cell(s).
