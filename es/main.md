# Proteus Viewer

Proteus es un visor DICOM, una aplicación especializada diseñada para mostrar e interactuar con imágenes médicas almacenadas en el formato DICOM (Imagen Digital y Comunicaciones en Medicina). DICOM es el estándar internacional para imágenes médicas e información relacionada. Este visor permite a los profesionales de la salud revisar, analizar y gestionar estudios de pacientes.

![Proteus Viewer](../images/viewer.png)

## Modos de Aplicación

Proteus Viewer tiene cuatro modos principales, cada uno con documentación específica:

- **[Visor](./viewer/main.md)** - Modo principal para revisar y analizar imágenes médicas
- **[Editor de Película](./film-editor/main.md)** - Cree diseños personalizados e imprima colecciones de imágenes
- **[MPR](./mpr/main.md)** - Visualización 3D avanzada y reconstrucciones oblicuas
- **[Volumen 3D](./volume/main.md)** - Renderizado interactivo de volumen 3D de series de TC

Seleccione el modo que está utilizando actualmente para ver su documentación específica.
