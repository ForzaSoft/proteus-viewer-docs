# Lienzo

El lienzo es el área de trabajo principal del Editor de Película. Muestra una o más páginas, cada una dividida en celdas de imagen según la plantilla seleccionada.

## Páginas

Una película puede contener múltiples páginas. Use los botones **Anterior** y **Siguiente** en los bordes izquierdo y derecho del lienzo para navegar entre páginas.

## Celdas de Imagen

Cada página se divide en celdas según la plantilla activa. Las imágenes enviadas desde el visor se colocan en las celdas de forma secuencial. Puede interactuar con las celdas individualmente usando los modos de ratón de la [Barra de Herramientas](./toolbar.md):

- **Selección**: Haga clic en una celda para seleccionarla. Las celdas seleccionadas se resaltan y pueden reposicionarse, ajustarse o eliminarse.
- **Ventana de Imagen**: Arrastre dentro de una celda para ajustar su brillo y contraste de forma independiente.
- **Mover**: Arrastre dentro de una celda para desplazar la imagen.
- **Zoom**: Arrastre dentro de una celda para ampliar o reducir la imagen.
- **Eliminar**: Haga clic en una celda para eliminar su contenido de imagen.

## Menú Contextual

Hacer clic derecho en cualquier lugar del lienzo abre un menú contextual con las siguientes acciones:

- **Seleccionar Todo**: Selecciona todas las celdas de imagen de la página actual.
- **Deseleccionar Todo**: Borra la selección actual.
- **Restablecer**: Restablece las celdas seleccionadas a su estado inicial (zoom, desplazamiento, ventana/nivel).
- **Eliminar**: Elimina el contenido de imagen de las celdas seleccionadas.
